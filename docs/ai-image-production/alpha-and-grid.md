# Alpha 与语义拆分差异

自然 BBox、等比适配、合法断开部件与透明验收通则见[静态素材资料](../game-asset-production/production.md)。这里只说明旧 Sharp 实现特有的行为，不重复游戏静态或动画流程。

## 阈值和 Alpha 字段

源 `inspect` 把任意 `alpha < 255` 计作透明像素，全图轻微半透明也会满足该字段。它不单独证明背景已被移除。

本工具组默认阈值为 8，与游戏静态脚本的默认 0 不同。更重要的是同组脚本对阈值的用途也不同：

| 脚本 | 实际作用 |
| --- | --- |
| `trim-transparent.mjs` | 用阈值求裁框，框内仍取原像素 |
| `split-grid-assets.mjs` | 仅为高于阈值的像素打组件标签；Mask 导出会清零所有未被选中的像素，包括框内低 Alpha |

所以拆分不能套用“只影响裁边、框内弱透明保留”的说法，光晕、烟雾与细粒子需要特别核对。

## 黑底色键

`black-key-to-alpha.mjs` 用 RGB 最大分量生成 Alpha 并重算 RGB。它是黑键，不是游戏视频链的绿幕判据，也不是语义去背景。

旧默认：全不透明亮度阈值 96、纯黑清空阈值 0、边框近黑阈值 8、边框近黑比例要求 90%。仅检查边框不能证明整幅背景连续或主体不含合法黑色；暗描边、黑底混合光效可能被破坏。告知参数只是调用者声明已说明风险，不是授权验证。

源码拒绝已有透明像素的输入；处理后检查可用 Alpha 与外沿触边。黑白灰底验收沿用共用检查，不在这里复制清单。

## 整图组件归属

游戏静态工具按已确认规则格位处理并拒绝跨格；这里先在**整图**识别组件，再把格子用作名称归属：

```text
cell → name
→ alpha 高于阈值的 8 邻域组件
→ 按各格有效像素数分配组件
→ 合并同格组件求 BBox
→ Mask 排除其他成员，导出完整组件
```

这是像素个数统计，不是 Alpha 加权或语义置信概率。轻微越格可能保留完整，完全脱离本格的粒子也可能误归到邻格。

旧脚本阻断最大归属并列、跨格最大占比低于 60%、任一配置格缺内容及未放行的源图外沿触边。这些门禁不是通用对象分割，也不保证发现所有粘连。

空格映射与非整除边界的具体缺口集中见[像素契约审查](migration-review.md#像素与布局差异)；不在两处维护修复清单。
