# 通用图片任务的差异

规格、尺寸、成员数量和交付通则引用[游戏素材资料](../game-asset-production/production.md)，这里不再写第二套生产流程。

## 非游戏任务与元素重建

完整插画、照片编辑和海报可以直接交付完整图片，不默认去背景。源技能把“分别拿到合图里的素材”默认解释为独立透明素材；明确只要等分或保留背景时另论。仅要求提示词时不启动生成。

需区分两种参考用途：

- **风格／对象参考生成**：借用身份、色板、笔触或构图创造新图。
- **指定元素重建**：从复杂图中选择一个对象、光圈、烟雾或玻璃元素，生成只含目标的新透明图；输出属于重建，不是原图切片。

原像素要求沿用[静态处理边界](../game-asset-production/production.md#不同素材的处理边界)。补充限制：旧技能没有完整的精细 Matting 执行器；半透明前景与背景从单张合成图分离可能不唯一，不能承诺无损还原。

## 与游戏技能不同的旧路由

| 能力 | 来源默认 |
| --- | --- |
| 普通生图、参考生成、风格迁移 | HubKKK 默认入口，跟随普通 `gpt-image-2` |
| 独立透明素材 | HubKKK 提示词透明直出；失败后考虑色底生成＋fal 去背景 |
| 指定透明元素重建 | HubKKK；旧 fal GPT Image 1.5 编辑为备选 |
| 语义去背景 | fal，可由用户偏好指定模型 |
| 本地像素处理 | Sharp 脚本，而非游戏技能的 ImageMagick 脚本 |

上述是旧版本事实，不是当前可用保证；路由缺口、公开 URL 与付费回退问题集中见[迁移审查](migration-review.md#路由与授权差异)，不在这里复制 API 参数。

## 个人偏好

源设计优先级是“本次明确要求 → 明确保存的长期偏好 → 技能默认”。一次性指定不改以后默认；只有明确要求长期使用才保存工具／模型或处理参数。具体存储位置需重新设计，本次没有读取旧偏好或建立新配置。

## 返回尺寸的旧经验

源文用请求比例与实际比例的相对误差 2%／5% 分档。它只是旧处理建议，不是裁切安全阈值：还需检查边缘内容和坐标配准，不能把某次尺寸漂移样本当平台固定行为。自然裁边、目标画布与不拉伸原则不在此重复。
