# 画风与质量修复

本页摘要整理文字参考，不复制长提示词模板或示例图。画风方向是可选约束，不是所有素材任务的默认流程。

## 何时应用画风

用户明确指定风格、要求分析参考画风或进行风格迁移时，才选相关视觉描述。“可爱、治愈、清新”应转成当前任务的形状、配色、线条和细节密度，不自动映射成某个命名方向。

规格与识别性沿用[共用静态约束](../game-asset-production/production.md#不同素材的处理边界)。这里只补风格冲突：模板里的纸张底、完整场景或装饰不能覆盖透明目标；只裁切／拆分时不重新风格化。

## 五类文字参考

| 源方向 | 可复用的视觉特征 | 需要按用途裁剪的内容 |
| --- | --- | --- |
| 波普复古矢量插画 | 粗轮廓、平面限色、半色调与印刷肌理 | 纸张背景不是透明素材必需项，黑轮廓不能配黑键去背 |
| 丑萌涂鸦 | 有意粗糙线条、夸张比例、随手上色和幽默表达 | 变形及额外碎线不能破坏用户规定的身份、数量和结构 |
| 可爱混乱蜡笔手账 | 蜡笔／彩铅颗粒、抖动边缘、贴纸感与粉彩色板 | 装饰与 UI 符号不是任务默认成员，避免遮挡主体或引入额外对象 |
| 现代都市动画电影感 | 细腻二维线稿、受控光影、冷暖色层次、空气透视与镜头感 | 城市、雨夜、霓虹等是场景要素，不应在只要画风时强加 |
| 白色手绘注释 | 白色细线、短注释、箭头与留白，保留原图内容 | 只标画面真实可见元素；口感、温度、人物内心等不是从图片即可确认的事实 |

最后一类更接近照片注释编辑，并非必须将照片改为插画。注释中的情绪化文案可以是明确的创作建议，但不能把未知感受或口感包装成已观察事实。精确文字需要另行核对或确定性排版，不假定生成模型一定正确。

## 瑕疵和有意纹理分开

| 要处理的问题 | 合理方向 | 检查风险 |
| --- | --- | --- |
| JPEG 块状、蚊噪、轻微彩色噪点 | 保守本地或专用降噪 | 细线、文字与轮廓是否被抹掉 |
| 分辨率不足 | 按需求评估超分／修复 | 新细节是推测，不自动等于还原原图 |
| AI 错误材质、结构性脏纹理 | 在授权范围内参考编辑 | 身份、构图、颜色和风格是否漂移 |
| 只希望下次生成更干净 | 改提示词中的具体瑕疵与完成度约束 | 不必先生成再额外修复 |
| 蜡笔、网点、纸纤维、胶片颗粒 | 若是明确风格则保护 | 不用统一的“无颗粒／无纹理”抹去用户目标 |

这些是方法分类，旧目录没有独立降噪、超分或精细 Matting 执行器。选择路线前还需确认实际工具和成本，不从一段方法说明宣称能力已接入。

## 修复后对照

修复特有的检查是：瑕疵确实减少、合法纹理仍在，没有塑料化、过度锐化或细结构丢失。其余规格、视觉和交付检查沿用[共用验收](../game-asset-production/production.md#局部修改与交付)。
