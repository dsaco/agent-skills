# 维护范围与验证状态

## 定位与范围

- dsaco 个人 Skill 集合，每个 Skill 独立分发，不针对某个应用定制。
- 本仓库维护技能内容、脚本、文档与测试；宿主加载、安装器和客户端发布由各工具负责。
- 自维护技能清单及外部技能安装指引统一见 [README](../README.md)，分发方式见[目录分发说明](distribution.md)。

## 验证基线

macOS / Node.js 24.14.0：仓库 `npm test` **37 项通过**。测试使用假凭据、临时目录、本机服务或内存网络替身，不调用真实付费 API。

| 技能 | 覆盖与限制 |
| --- | --- |
| fal-ai | 参数、任务恢复、下载与凭据边界、独立目录运行；详见[来源与验证](fal-ai.md) |
| volcengine-ark-media | Seedance 2.0／2.5 参数与 MOV 下载、提交保护、任务状态、图片恢复和独立运行；详见[来源与验证](volcengine-ark-media.md) |
| dashscope-tts | A/B 参数隔离、非流式合成、提交留据、补下载和错误处理；详见[来源与验证](dashscope-tts.md) |

技能分支与完成条件的静态检查见[流程走查](skill-process-review.md)，不等同于独立模型行为评测。

## 未验证范围

- 真实付费 API、账户权限、成品音质／画质，以及全部模型的实时参数和价格。
- Node.js 22、Windows、所有文件系统及宿主的兼容性。
- 第三方 Skills CLI 的真实安装流程，以及 README 所列外部技能的安装、运行和评测。
- Agent 自主触发率、跨模型流程遵循率。

百炼部分参数已核对公开官方文档，依据见该技能的来源记录；文档核对不等于真实 API 验收。安装与实际处理应分别确认依赖、权限、凭据和费用。
