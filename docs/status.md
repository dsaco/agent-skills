# 维护范围与验证状态

## 定位与范围

- 个人 Skill 集合，每个 Skill 独立分发，不针对某个应用定制。
- 自维护技能清单及外部技能安装指引统一见 [README](../README.md)，分发方式见[目录分发说明](distribution.md)。
- 本仓库维护技能内容、脚本、文档与测试；宿主加载和第三方安装器行为由各工具负责。
- Git 跟踪采用根目录与自维护 Skill 白名单；未知技能、安装状态、凭据及运行产物默认忽略。文本策略由 `.gitattributes` 定义，仓库根不设置统一 Node.js 模块类型。
- 本地直接维护用户目录下的 `.agents`，不依赖另一份开发仓库。第三方技能不随本项目提供，需各机按上游安装；已有宿主链接是否有效需要单独检查。

## 源码基线

fal-ai、volcengine-ark-media、dashscope-tts、qiniu 四个 Skill 完整目录来自 `dsaco/agent-skills` 提交 [`7e7e3f4933d680d698ca7f45d029b1c9e077e716`](https://github.com/dsaco/agent-skills/commit/7e7e3f4933d680d698ca7f45d029b1c9e077e716)，共 45 个技能文件。导入时逐文件 SHA-256 一致，包含文档、脚本、测试和独立 LICENSE；不包含依赖、凭据、生成媒体或任务记录，未导入旧 Git 历史。

exe-dev 从本地自维护版本单独整理，来源提交和 SHA-256 见[来源摘要](exe-dev-source.json)，结构调整及官方资料核对见[来源与验证](exe-dev.md)；不是对原目录的逐字复制。

更早的技能来源与变化保留在各技能的来源文档和摘要中。上述校验是导入基线，不要求后续维护保持文件不变，也不是发布者签名。

## 收录与维护验收

1. 核对来源和完整文件清单；导入时保留来源项目既有改动，不迁入凭据、依赖或真实任务记录。来源摘要记录历史版本，不保证原目录仍存在。
2. 对比同名技能差异和跨 Skill 调用，明确保留的能力与接口，不静默丢失功能。独立技能的测试不证明尚未接入的消费者已经兼容。
3. 核对许可、依赖声明及相对引用；独立目录可以完成匹配的离线验证。
4. 明确各宿主实际加载路径；检查 Mac／Windows 的路径、换行、依赖及权限差异。
5. 删除、替换、安装与发布按本次明确授权执行；备份策略需事先确认，远端关联不等于推送授权。规则见 [AGENTS.md](../AGENTS.md)。

## 未验证范围

- 真实付费 API、七牛上传／CDN 可访问性、账户权限、成品音质／画质，以及全部模型的实时参数和价格。
- Node.js 22、Windows、所有文件系统及宿主的兼容性。
- 第三方 Skills CLI 的真实安装流程，以及 README 所列外部技能的安装、运行和评测。
- Agent 自主触发率、跨模型流程遵循率。
- exe.dev 的真实 SSH、分享、代理认证、peer、计费账户、VM 操作和安全架构实施；确定性测试仅检查结构，不从指定安全句子存在推导行为正确。
- 与旧版 fal-ai 视频接口及游戏素材等尚未迁入技能的兼容性；当前 fal-ai 仍是图片版。

百炼部分参数已核对公开官方文档，依据见该技能的来源记录；文档核对不等于真实 API 验收。安装与实际处理应分别确认依赖、权限、凭据和费用。
