# strudel-music 验证与许可

## 许可

文档与脚本采用 MIT（见技能目录 LICENSE）。技能通过浏览器使用第三方站点 strudel.cc，不复制 Strudel 代码；渲染成品中的采样库许可未核对，技能文档要求商用前按实际用到的库核对。

## 验证

macOS / Node.js 24.14.0 / Python 3.13.1 / ffmpeg 9.0.1 / Playwright 1.61.0 与本机 Chrome：

- 仓库 `npm test` **57 项通过**，其中本技能 8 项离线测试、1 项仓库结构检查：参数解析、预检分析、CLI 在联网前的拒绝路径、中文空格目录、计时、WAV 校验（含削波）、双循环截取；不启动浏览器、不联网。
- 2026-10-15 在 strudel.cc 实测：
  - 预检：4 小节测试曲通过；问题样例报出未知声音、循环错位和 orbit 冲突；语法错误约 7 秒报出且不进入导出；含 `?` 随机的样例两次运行结果相同。
  - 对 14 份实际作品源码执行 `--check-only --loop`：时长与源码头部规格一致，循环一致；检出 4 份引用默认声音表中没有的名字（如 `birds`、`tabla2`、TR-606 的 `cp`），1 份用 `stack` 拼接段落，声音的小节分布与注释计划不符。
  - 渲染：4 小节测试曲约 12 秒完成；440 Hz 单音测试估计 439.5 Hz，确认导出使用当前源码；64 秒 7 层作品约 45–47 秒。
  - 增强双循环：截取结果 8.000 秒、16 位，首尾样本跳变从 0.0099 降到 0.0002 满幅。
  - `--list-sounds` 返回 1655 个声音，分类计数见技能的音色参考。

未验证：Windows、Linux、Node.js 22、其他 Strudel 部署、自备采样加载、成品听感、采样库许可、模型自主触发率，以及与 ElevenLabs `music` 技能同时安装时的路由选择。strudel.cc 改版或声音表变化可能使脚本或参考清单失效。
