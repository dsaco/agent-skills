## 保留的定位

- 面向能被游戏使用的 2D 资源，而不仅是概念图：静态图片、背景、状态变体、连续动画帧、帧表及元数据。
- 规格来自当前任务；成员身份、相对尺度、状态对齐、动作时序和消费方锚点都需要保留，不能只按单张图是否好看来验收。
- 与通用图片技能独立，不继承其工具偏好，也不把它设为必经入口；图像生成／去背景交给底层服务能力，像素与几何处理交给本地工具。
- 原能力不覆盖通用引擎导入、自动动作理解、骨骼动画、3D、音效或游戏业务代码；有本地复制入库脚本不等于引擎集成或正式发布已经实现。
