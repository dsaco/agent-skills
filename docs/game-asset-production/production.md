# 规格与静态素材

本页保留旧技能中可复用的生产判断，不提供新项目的执行入口。脚本现状见[工具清单](tools.md)，生成依赖差异见[迁移审查](migration-review.md)。

## 从当前输入建立规格

需求文档提供成员、状态、关系和交付约束；参考图提供可见外观，当前请求决定这次处理的子集。没有参考图可以设计候选，不必强求示意图；没有对象、用途或范围则不能靠历史项目猜测。

| 维度 | 需要确定 |
| --- | --- |
| 任务与成员 | 本次对象、数量、名称、静态／状态变体／动画，以及需保留的已完成资源 |
| 外观 | 身份、轮廓、材质、视角、风格、固定属性与允许变化的属性 |
| 关系 | 同一／不同成员、共享坐标、相对尺度、方向、锚点和分层关系 |
| 几何与时间 | 生成画布、最终尺寸、动画帧序／时长／循环；各自分开记录 |
| 交付 | 格式、Alpha、命名、候选目录、正式资源目录与真实导入契约 |
| 依据 | 来源章节或用户说明；明确要求、计算推导、设计建议和待确认冲突分开 |

例如总时长不唯一决定帧数，资源名称不唯一决定外形，参考图没有某个部件也不代表可删除文档要求的部件。仅询问影响当前目标的关键缺失；授权先设计候选时，清楚标出假设。无视觉基准的付费系列可先做代表样本，但不能未经授权扩批或重试。

## 原图片路线

源版本默认 fal.ai GPT Image 2.5 Flare：无参考用 `openai/gpt-image-2.5/flare/text-to-image`，有指定参考用 `openai/gpt-image-2.5/flare/edit`。独立素材显式请求透明背景，默认 PNG；完整背景按用途请求不透明输出。

这只是原默认值记录，不是本次新调用授权或最新接口背书。新仓库的[图片模型说明](../../skills/fal-ai/references/images.md)包含 Flare，但命令与任务记录协议不同，旧示例不能直接复制执行。更换模型或视频服务商也不是文档整理的隐含动作。

透明直出后先检查真实 Alpha、有效内容与边缘，已有合格透明图不重复去背景。尺寸、边缘或编码问题优先复用原图处理；内容／结构失败才考虑额外生成，并单独确认费用与次数。

## 不同素材的处理边界

| 类型 | 可保留的处理思路 | 不能混用的操作 |
| --- | --- | --- |
| 独立单体 | 全部合法部件共同求 Alpha BBox；未指定尺寸时保留自然尺寸 | 不只保留最大连通域，不强制正方形或填满画布 |
| 独立系列 | 先记录成员映射、数量与排列，再选择合图或逐项生成 | 请求返回图片数不等于不同成员数；连通组件数不等于语义数量 |
| 状态变体 | 保留身份、公共坐标、相对尺度和锚点，只改变规定属性 | 不能逐项紧裁后各自最大化缩放 |
| 完整背景／分层背景 | 核对比例、玩法区域、遮挡、UI 留白及接缝 | 不默认去背景或按单体 BBox 裁切；无专用工具就不声称自动平铺验收 |
| 精确符号／几何／计数 | 优先确定性绘制、合成与逐项核对 | 不以生成图近似结果替代精确契约 |

AI 参考重建和保留原像素提取应分别命名。要求原像素时，需遮罩／分割／抠像路线；没有工具就说明能力限制，不偷偷改成重绘。

## 旧静态脚本的确定性范围

`prepare-static-sheet.mjs` 使用 Node.js + ImageMagick 7，面向已人工核对语义的独立静态规则合图。源码要求：

- 实际 PNG／WebP、有完全透明像素和有效内容；实际宽高可被行列整除。
- 清单显式映射成员与格位；未登记格应为空，重复格位和不安全名称拒绝。
- 写素材前预检全部格位；内容触及 cell 边界时停止，不沿格线截断主体。
- 默认 Alpha 阈值为 0；提高阈值需要确认弱透明是残留而非合法内容。裁切保留框内原 Alpha，阈值不是通用去噪。
- 每项可保留自然尺寸或等比 contain 到指定画布；像素风可显式选用近邻采样。
- 输出到新目录，保留裁前来源、裁后未缩放图、最终图、黑白灰底预览及技术报告；失败报告不代表完整交付。

它不具备通用语义分割、跨格归属或状态／动画对齐能力。与通用图片技能的整图连通域拆分不是同一个算法，不能互换名称后当作等价实现。

## 局部修改与交付

已认可风格后只修用户点名项，用当前认可结果作参考；未改成员可按字节复用并核对，不重新编码或生成。比例／造型问题不靠非等比拉伸掩盖。

交付分三类判断：

- **技术**：实际格式、尺寸、数量、Alpha、内容完整性和成员映射。
- **视觉**：身份、结构、风格、系列关系、小尺寸可读性与黑白灰底边缘。
- **使用**：消费方的显示、锚点、切片或引擎契约；未测试就明确未验证。

先给透明成品的位置，再注明加底色预览只供检查。原始输入、候选、预览与正式资源分开；本地生成候选不自动授权替换正式文件、提交或发布。
