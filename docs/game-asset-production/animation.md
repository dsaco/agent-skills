# 动画路线与后处理

源资料记录了图片帧表和视频抽帧两条路线。下文是方法与旧实现边界，不是本次重现的模型效果，也不意味着当前新项目已有完整执行链。

## 先确定动作契约

动画额外明确身份参考、起点、关键阶段、终点、轨迹／转轴、接触关系、帧序、帧数、时长、循环或单次、共同画布及锚点。文字分镜可以替代动作示例；主体参考锁定身份，动作参考只提供变化，不混入另一主体的风格和部件。

均匀时长时 `duration = frameCount / fps`；非均匀时长以逐帧时间为准。总时长、整数毫秒分配、末帧停留和演示循环要相互一致，源视频长度不是成品动画长度。

没有通用的八格、十二帧、固定朝向或最低交付尺寸。旧动物任务中的这些设置应由本次规格替代，不能升格为所有动画的默认要求。

## 两条路线

| 路线 | 历史使用范围 | 代价与限制 |
| --- | --- | --- |
| 参考／文字分镜 → Flare 透明帧表 → 后处理 | 物件状态变化、部分空间姿态变化、重视 Alpha 的输出 | 身份和动作连续性需人工检查；图片逐格重绘对交替步态可能不稳定 |
| 高清首帧 → 图生视频 → 分析选窗 → 去背景 → 后处理 | 源记录中的两足／四足交替动作 | 多一层视频生成与可能的逐帧去背景费用；压缩、朝向变化、阴影和边缘损失 |

源样本不足以认定某条路线总是更优。路线切换、额外生成和逐帧费用按任务授权处理，不靠反复付费尝试掩盖输入冲突。

### 视频准备与选窗

可复用的检查包括：

- 首帧使用足够清楚的来源，核对实际朝向、完整轮廓、运动余量和画布比例。镜像会改变文字、左右配件等语义，只有允许时才使用，不能一概当作身份不变。
- 纯色底与主体填充、描边、阴影及半透明边缘强分离。换成蓝幕不能自动让仍使用绿色判据的后处理变成蓝幕抠像。
- 首尾使用同图可以作为闭环约束线索，**不保证**模型产生像素相同的首尾或无缝循环；成品仍需实际播放验收。
- 分析周期时关注基本周期、半周期／倍周期误判、漂移及首尾衔接。旧分析器会输出推荐周期和帧集，指标是辅助证据，不是动作理解或人工认可。
- 去背景前先确认最终帧集，避免为不交付的整段视频逐帧付费。源帧号、窗口序号与输出序号分别记录，防止换帧后错配。

旧批处理直接采用推荐帧集继续执行，缺少该人工确认门槛；详细差异见[迁移审查](migration-review.md#批处理不是通用自动生产)。

## Alpha 与残留处理

旧视频链的两种抠像方式：模型去背景，或背景适合时使用本地绿色判据。模型去背景后还有本地 Alpha 下限、去溢色与边缘颜色修复；它们会改变像素，不能笼统称作无损。

- 绿色判据可能伤害主体自身绿色，去溢色也可能改变眼睛、装饰等合法颜色；阈值、背景色和关闭选项需要按实际素材验证。
- 提高 Alpha 下限可能保住细部件，也可能保住不属于主体的内容，不能保证只恢复正确前景。源视频中已经丢失或混色的细节不能靠该步骤恢复。
- `detect-residue.mjs` 按连通域筛查分离残片；与主体连通的阴影可能漏检。“该检测器找不到”不等于所有后处理都无法处理，更不等于可以跳过目检。
- 逐帧检查细腿、尾巴、边缘与脚底，再在目标尺寸及黑白灰底上看实际效果；静态接触表和统计值不能证明时间连续性。

补跑只针对已确认有问题的帧，同时冻结最终帧序；新视频、新选帧和新修复参数应分别有身份，不能仅按输出文件是否存在来认定可复用。

## 共同坐标与缩放

独立静态紧裁不适用于动画。默认保留合法运动：从所有帧求共同内容范围，统一裁切、缩放和输出偏移。目标画布为 `targetW × targetH`、安全边距为 `p`、共同范围为 `W × H` 时，可用 `min((targetW - 2p) / W, (targetH - 2p) / H)` 作为统一缩放比例。

旧打包器有三种垂直摆放：

- `center`：共同范围居中。
- `bottom`：共同范围整体贴底，保留各帧原有起伏。
- `bottom-per-frame`：逐帧最低有效像素贴底，会改变逐帧位置；仅适用于已确认的原地动作和稳定脚底锚点，不自动适合跳跃、悬浮或位移动作。

多组动作切换还要核对共同锚点及相对尺度，不用逐帧独立放大消除透视、形变或合法运动。图片帧跨格但完整分离时，可在核对透明切线后用显式 ROI 修复；被源图截断、互相覆盖或语义不清时不声称裁切能恢复。

## 打包与验收

当前旧脚本可输出透明帧、PNG／WebP 帧表、自描述 JSON 和 HTML 播放器。保留关键契约：

- 每帧矩形、顺序、尺寸、时长、循环方式、锚点与坐标变换相符。
- 从帧表回切比较解码像素；严格 RGBA 一致时，旧链使用 lossless + exact WebP 并复验，不仅看文件大小或后缀。
- 原速、慢放、单次结束状态和循环接缝分别检查。播放器无报错只证明播放程序运行，不证明动作自然或用户认可。
- 预览 GIF 的调色板、透明与时间精度有限，展示用循环／停留不写回正式时序。
- 首帧是生成重建还是原像素复用分别报告；通用元数据不等于任意引擎原生导入格式。

仅改变交付尺寸通常可从保留源帧重打包，无需重新生成；但旧重打包工具的写入、覆盖和固定尺寸假设需先整改，见[工具清单](tools.md)。
