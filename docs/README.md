## 阅读口径

- **源码事实**：从记录的源版本静态核对到的行为，不等于真实接口仍可用。
- **历史观察**：源作者记录的特定时间／版本现象，未在整理时重现。
- **建议**：从风险推导的检查方法或设计要求，不是平台保证。
- **待核对**：有矛盾、缺证据或可能已变化的规则，应用前查当前官方文档、控制台及目标账户条件。

日期、金额、配额和审核结论按上述口径理解；不把整理日期当成重新实测日期。涉及账户、付款、上传、部署和权限变更另需授权；这里的文档不构成执行授权。资料不包含真实凭据、账户标识、任务记录或原始生成媒体。

来源文件清单和 SHA-256 在各主题的 `sources.json`，记录整理时的历史版本，不保证原目录或执行文件仍在本机；仅用于溯源，不是签名。整理内容沿用仓库 [MIT](../LICENSE)；引用的第三方文档、标准和服务权利仍归其权利人，不复制官方全文或第三方程序。
