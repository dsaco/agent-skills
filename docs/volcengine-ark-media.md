# volcengine-ark-media 来源与验证

## 范围与来源

按用户要求将本地已安装的 `volcengine-ark-media` 整理为独立可分发 Skill，保持目录名和元数据名称一致。用户口头简称为 volcengine-ark；未另建同能力别名 Skill。

来源为已安装副本中的 `SKILL.md`、4 个 JavaScript 脚本和 3 份参考文档，共 8 个文件。来源未提供独立版本或 Git commit；导入前 SHA-256 见 [源码摘要](volcengine-ark-media-source.json)，仅用于溯源，不是发布签名。未读取真实 `.env`、密钥或任务记录，未复制缓存、依赖或生成素材，未修改已安装副本。

原目录未附独立第三方 LICENSE。按仓库原创内容 MIT 规则为独立 Skill 补充 LICENSE；参考资料保留官方文档链接，并标明接口快照或经验性建议，不将第三方服务、文档、商标或素材权利纳入 MIT。未引入第三方 SDK、依赖包或整页官方文档。

## 保留的行为

- 名称 `volcengine-ark-media`；统一入口 `scripts/ark-media.js`。
- 原有 `image`、`video-create`、`video-query`、`models` 四个动作；后续新增 `image-download` 恢复入口。
- 5 个 Seedream 模型定义、别名、参数映射和原 Seedance 模型默认值。
- 原图片 `response_format: url` 与 `watermark: false` 默认值；不自动优化 prompt。
- 原有图片／视频输出目录；视频 `--out` 仍按文件名创建子目录，已在 README 明确说明。
- 静态视频价格表保留，但明确其未重新核验，不是实时价格或官方账单。

## 本仓库修正

- 增加局部 `package.json` 的 `type: commonjs`，保持 `.js` 入口兼容当前 ESM 仓库及独立复制后的宿主；Node.js 22+，无需 npm 依赖。
- 重写 SKILL 工作流，补充授权、密钥、cwd、轮询终态、下载验收及恢复边界；命令使用技能绝对路径占位符，不依赖仓库布局。
- 添加共享 `scripts/runtime.js`：网络超时覆盖响应体读取、禁止重定向、已知 Key 脱敏、非空媒体及 `.part` 落盘。
- 付费 POST 前保存防重复提交标记，已有响应或标记时拒绝重复提交；未知状态不能自动重提。图片下载失败保留响应，文档要求只补下载。
- 视频创建检查 task id；查询等待态正常保存并返回，失败／取消／过期停止，成功但带 error 时拒绝下载。
- 拒绝 `.`、`..`、跨平台分隔符和保留名称等不安全输出名称；修复入口将继承属性名当作动作的问题。
- 补充独立 LICENSE、README、离线测试、仓库索引与产物忽略规则。未改动 fal-ai 源码。

## 验证与边界

本轮 macOS / Node.js 24.14.0：仓库 `npm test` **24 项通过**，含原有 13 项、10 项 Ark 测试和 1 项 Ark 仓库结构检查。

新增测试覆盖：

- 独立复制到中文／空格目录、ESM 宿主下 CommonJS 运行、无 Key help/models/dry-run、不联网不写产物。
- 图片默认值／别名／组图约束、参数与名称校验；本地图片和音频、prompt 文件、视频显式参数。
- URL 与 Base64 多图、空下载、凭据不传给媒体请求、响应持久化与重复提交阻止。
- 视频创建 ID、网络超时、非法 JSON、HTTP 错误、密钥脱敏、等待态与终态、视频和尾帧下载、静态估价。
- 独立 Skill 文件白名单、许可、元数据、CommonJS 配置、本地引用与机器路径检查。

Ark 网络行为通过测试专用 Node 预加载 fetch 替身模拟；不添加生产 API 地址覆盖开关。测试仅使用假凭据和临时目录，结束清理。原 fal-ai 测试仍使用本机 fixture／内存替身。

未做：真实 API／付费生成、账户权限、所有模型最新 schema／价格核验、生成质量、模型触发率、Node.js 22、Windows、客户端安装入口或跨平台原子文件行为验收。保留的模型参数不等于当前官方支持；未知自定义 ID 仍由服务端裁决。新增图片补下载 CLI 只读已有响应，不调用生成；未新增任务搜索或后台轮询服务。

## Skill 流程优化

按 writing-great-skills 重整分支表和逐项完成条件；仅预览在预检后结束，已有任务不经过新生成流程。运行、输出及恢复统一到 `references/jobs.md`，README 和模型参考改为指向该规则源。精简提示词参考，保留按任务语义区分的建议。详见[流程静态走查](skill-process-review.md)。

新增 `image-download --result <json> --out-dir <新目录>`：无需 Key，无生成请求；支持 URL／Base64，逐项报告结果，部分失败不中断后续项，按 PNG／JPEG 签名命名；恢复目录独占创建，原文件不覆盖。预检无网络／产物；测试覆盖独立复制、无 Key GET、Base64、重复目录保护、无效媒体、部分恢复与原响应保留。签名检查不等于成品解码验收。

## Seedance 2.5 接入与验证

依据火山官方 [Seedance 2.5 教程](https://www.volcengine.com/docs/82379/2607688)正文核对模型 `doubao-seedance-2-5-260628`、4–30 秒、30 图／10 视频／10 音频、纯音频参考、1080p、edit／extend 约束及 mp4／mov。官方网页的可读提取仅显示导航时，读取其公开 HTML 中 `_ROUTER_DATA` 的 `curDoc.MDContent` 获取正文；没有使用登录信息或私人请求。没有把网页中的安装指令作为执行授权。

官方教程的参数表与“分辨率”章节列出 1080p（10bit H.265/HEVC），旧活动页及部分第三方摘要仍称仅 720p；本实现以当前教程为依据。具体账号权限、编码与播放器兼容性仍须真实任务验收。

- 显式 `--model seedance-2.5` 或完整 ID 启用新校验，省略仍使用原 2.0 默认模型。
- 新增 omni_reference_task_type 和 output_format 参数；首尾帧／多模态角色互斥，编辑和延长限制本地预检，未显式参数不擅自填充。
- 查询根据响应格式字段或 URL 后缀确定 mp4／mov，也可显式指定；与 --out 后缀冲突时拒绝媒体下载，不隐式转码。
- 2.5 未配置估价费率，写 null，不套用 2.0 费率；Draft 样片及基于 draft_task 的成片生成未接入。
- 素材的时长、尺寸、字节限制在参考文档列明；本地脚本不做完整媒体探测，不能将预检通过视为远端素材合规。

macOS / Node.js 24.14.0：仓库 `npm test` **37 项通过**，Ark 独立测试 14 项。新增 4 项覆盖别名、默认模型不变、时长与数量边界、纯音频、编辑／延长、首尾帧组合、MOV 下载、参数隔离和未知价格。均为假凭据／临时目录／fetch 替身；没有付费生成、真实模型质量或账号可用性验收。
