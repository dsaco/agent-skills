# 云环境、身份与迁移

本页整理历史知识，不给出当前套餐报价或未经验证的迁移命令。[资料口径](../README.md#阅读口径)适用于下文。

## AppID、环境与身份

**可保留的检查思路**：代码迁移不等于资源或用户身份迁移。评估 AppID 变化时，分别核对以下对象：

- 环境所有权、授权调用方、计费账号和可用地域。
- 小程序端环境配置、云函数运行环境、数据库及存储访问规则。
- openid／unionid 的取得条件、用户映射和业务授权；不能假定更换 AppID 后 `_openid` 仍匹配。
- 订阅消息模板、云函数权限及环境变量、媒体 fileID 引用。

源记录建议云函数用 `cloud.DYNAMIC_CURRENT_ENV`，小程序端显式配置目标环境；这是减少硬编码的方向，仍需检查代码中其他环境引用。

**环境共享待核对**：源记录将其描述为跨 AppID 复用路线，并给出 `resourceAppid`／`resourceEnv` 配置。但初始化／调用方式、适用主体、授权范围和返回身份取决于当前 CloudBase 接口，不能把旧片段当通用调用契约。尤其“共享后 openid 一律按主方计算”和“这是唯一官方路径”没有在此次整理中验证。共享方案还需考虑资源方存续、计费与撤销后的影响。

## 计费旧记录：只作为核对清单

源 `cloud-env.md` 标注“2026-01”，记录过：免费体验环境名额、每月 3000 资源点、单次 6 个月／手动续期、发布后到期调整为第 15 天，以及旧低档月费约 ¥19.9。还写有“每账号最多 2 个环境”。**这些数字、账户口径和发布规则均未重新核对，不据此承诺免费期或确定预算。**

使用前在目标账户的当前控制台核对：

| 项目 | 要取得的依据 |
| --- | --- |
| 套餐 | 产品线、账户适用套餐、免费名额／有效期及续期方式 |
| 上线影响 | 正式发布是否改变有效期、到期停服／回收规则 |
| 超量 | 限停还是按量计费、是否自动开通、资源包条件 |
| 升级 | 环境 ID、数据和配置是否保留，切换时间及回滚限制 |
| 总成本 | 套餐外的调用、数据库、存储、流量及其他云资源 |

源记录将免费转付费描述为“原地升级”。它可以作为优先核对的路线，不能免除备份和升级影响确认；“发布后必然付费”也不能脱离具体套餐推广。

## 迁移核对表

| 对象 | 迁移前后核对 |
| --- | --- |
| 目标归属 | AppID、腾讯云账号、实际环境 ID、套餐、权限相符 |
| 应用与函数 | 客户端目标环境、全部函数及依赖、版本与运行状态；逐函数超时、权限、变量、触发器分别检查 |
| 数据库 | 集合、字段、复合索引顺序／升降序／唯一性、安全规则；默认规则按当前环境确认 |
| 数据与身份 | 逐类用户映射；unionid 只有满足平台条件时才可用，也不意味着它是唯一可能的业务映射 |
| 存储 | 上传后文件标识、域名／访问权限及数据库中全部引用 |
| 订阅消息 | 新 AppID 模板、字段编号和所有发送／订阅配置同步，见[消息资料](messages-and-payments.md) |
| 验收 | 登录、写入、读取、媒体、定时任务、订阅主链路；确认实际落入目标环境 |
| 退出旧环境 | 确认所有消费者已切换、有恢复依据，再单独审批停用；测试数据是否放弃也由用户决定 |

源记录的函数“默认 3 秒、改成 20 秒”、触发器／索引“没有导出功能”等属于当时工具和环境表现。当前能力先查版本与帮助，超时按任务预算选取，不套固定数值。

## 历史异常及适用边界

### 云函数 openapi 返回 `-501001`

源作者在 2026-08 的内容安全和订阅消息场景记录过平台代持 token 路径失败、直接 API 路径成功，重新登录开发者工具未恢复。

**可保留的判断方法**：分离凭据／权限、AppID 归属、目标接口及云平台调用链。错误码本身不能排除代码、SDK、计费或权限因素；一次直接调用成功只缩小故障范围。

源记录的 stable_token 绕行涉及 AppSecret 和生产代码变更，本资料不提供可直接执行的绕行。应先查当前 token 机制、平台状态和工单，若另行实施，明确缓存、刷新、失效、权限和回滚，不代用户上传真实密钥。

### 新环境数据库路由不一致

源作者在 2026-08-11／12 记录过 manager-node 的环境信息、读库与写库出现相互矛盾；早期猜测别名重名，后续不同别名案例推翻了“重名是唯一原因”。没有足够证据认定根因或固定传播时间。

**建议**：写入前核对账号和环境归属，在隔离环境以只读证据交叉检查；发现目标不一致立即停止写入。`getEnvInfo` 一项正确不代表所有数据面请求都正确。部署到目标环境内的函数可作为另一条核对路径，但不是无条件“唯一可信”的保证，也不应拿生产库写探针。
