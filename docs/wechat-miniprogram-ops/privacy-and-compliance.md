# 隐私、审核与内容合规资料

本页是历史问题清单和设计检查，不是法律意见或现行平台审核保证。政策结论使用前核对对应主体、类目、接口、版本和当前官方要求。

## 隐私指引：先处理源文件矛盾

源 `privacy-guideline.md` 前段写“`wx.setClipboardData` 与读取剪贴板同属声明项”，后段又写“写入剪贴板不用勾”。**两者不能同时成立，本资料不选边作为通用结论。** 应按当前接口隐私对照表、提交代码扫描结果及后台要求核实。

可保留的核对顺序：

- 从实际代码和依赖枚举隐私相关接口，再对应后台声明；包括媒体选择、摄像头、录音、定位、保存相册、剪贴板、用户资料和传感器。
- `chooseMessageFile` 与照片选择可能对应不同项；仅上传存储与写系统相册也是不同动作，按当前官方分类确认。
- 云函数获取 openid 不等于申请昵称头像，但仍需在完整隐私处理说明中评估其用途与数据责任，不能推导成“没有隐私义务”。
- 声明、隐私政策、授权界面与实际行为相互一致；开发工具、体验版、正式版各自验证。源记录的“开发版不拦截、其他版本一律拦截”和审核耗时不作为固定契约。

用途文案优先写实际动作与业务场景，例如“拍摄上传图片”“录制语音”；不为过审虚构用途。后台要求、告知方式和同意机制依当前规则选择，“弹窗最容易通过”只是源经验，不替代有效同意和真实告知。

来源入口：[微信小程序隐私相关文档](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/)。

## 备案：建立名称、功能和分类的关联

源记录中有“名称与类目／备注无关联”的驳回案例，可提炼为：简介说明产品是什么、名称与功能如何关联、实际功能对应哪个分类。备案表的服务内容和 mp 后台服务类目不是同一套分类，分别核对。

- 优先修正真实功能描述与分类，不把增加营销词或改名作为必需步骤。
- 备注采用普通文本，检查复制时混入的 Emoji、表格线等；哪些字符允许以当前表单校验为准。
- “只选一个分类”“个人主体范围更窄”等旧建议不能脱离实际服务与主体判断。

泛化示例（不是已通过审核的承诺）：

> 某某备忘是一款备忘录工具，支持记录和整理文字、图片与语音，方便后续查找和回顾。

## AIGC 标识与类目资质

源记录引用《人工智能生成合成内容标识办法》及 GB 45438-2025，并记录实施日期为 2025-09-01。这里保留查证对象，不在未经复核时将适用范围、例外或实施日期写成面向所有业务的结论。

待查的核心问题：

| 范围 | 需要核实 |
| --- | --- |
| 责任主体 | 生成／传播／使用方分别承担什么义务，实际产品属于哪类服务 |
| 显式与隐式 | 展示提示、文件元数据、数字水印的各自要求与适用例外；不能认为任一种天然替代其他项 |
| 文件链路 | 生成、加工、存储、CDN 和下载是否保留应有标识；不能只比较文件大小判定成功 |
| 字段格式 | 标准对应版本、服务提供者名称／编码规则、唯一内容 ID 与传播字段 |
| 上架资质 | 算法备案、合作协议、主体和服务类目的当前要求 |

源文件记录了 XMP 命名空间 `http://www.tc260.org.cn/ns/AIGC/1.0/`、`TC260:AIGC` JSON，以及 `Label`、`ContentProducer`、`ProduceID`、传播／保留字段；这些是**待按标准正文验证的格式线索**。其中“用名称即可合规”“历史内容不用处理”“仅最终产物需标识”的绝对说法未获本次确认，不直接沿用。

如以后实现，应读回并校验实际交付文件的元数据与标识，在格式转换后重新验证；PNG iTXt／JPEG XMP 的具体写入和标准兼容性另做测试，不从第三方示例直接推导法律合规。

查证入口：[国家网信办](https://www.cac.gov.cn/)、[国家标准全文公开系统](https://openstd.samr.gov.cn/)、[全国网安标委](https://www.tc260.org.cn/)。本次没有下载标准全文或重新核实监管条文。

## 联系方式、引流与客服

源记录把“小程序页面不能放任何微信号、二维码、手机号”“个人主体只有一种沟通渠道”“邮箱／表单没有违规风险”“微信客服等于一键加好友”写得过宽。

整理后仅保留风险区分：

- 合法服务联系、诱导添加和引导站外交易是不同场景，需核对当前运营规范、主体、类目和文案。
- 小程序客服消息与 `wx.openCustomerServiceChat` 对应不同能力，后者的主体／绑定要求和实际打开行为按接口文档确认，不能等同自动添加私人好友。
- 消息回复窗口、是否免费和个人主体限制均可能变化；邮箱／留言表单同样涉及隐私、内容管理与平台规则。
- 客服对话也不天然豁免运营规范；不以“被动告知”保证审核或巡检安全。

来源入口：[小程序运营规范](https://developers.weixin.qq.com/miniprogram/product/)、[客服接口](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/customer-message/wx.openCustomerServiceChat.html)。本页未做当前政策背书或后台配置。
