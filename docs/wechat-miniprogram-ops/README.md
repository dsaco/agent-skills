## 需要优先核实的源资料问题

1. `wx.setClipboardData` 的隐私声明要求在同一源文件中相互矛盾，不能直接选一条作为结论。
2. “跨 AppID 共享后 openid 按主方计算”“每账号最多两个环境”等说法涉及产品版本与调用上下文，缺少可复核的完整依据。
3. 免费期、发布后到期、支付沙箱、审核时长、客服主体限制等有时间与账户条件，历史记录不等于现行政策。
4. `setup-db.js` 的环境读取行为与说明冲突，且缺少写入前归属核验；本项目不提供它作为模板执行。

## 后续使用前的门槛

- 先识别目标 AppID、主体、环境、套餐、基础库与工具版本；仅记录必要的脱敏信息。
- 政策按当前平台页面核对，测试用隔离账户／环境和合成数据；付费与真实用户消息测试需另行授权。
- 涉及凭据时仅在用户本地受控流程配置；不将真实 `.env`、AppSecret、SecretKey、session_key 或签名放入对话、资料或公共仓库。
- 如以后接入 Skill／脚本，先明确许可、跨平台入口、最小权限、只读预检、提交留据与结果未知时的恢复规则。

本次没有登录微信／腾讯云、调用云 API、创建环境、发送消息、测试支付或复现历史客户端问题。
