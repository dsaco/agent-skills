# GitHub Skill 分发契约

## 来源与信任

固定公开仓库 `dsaco/agent-skills`，默认分支 `main`。Skill 是 `skills/<name>/` 直属目录，包含同名 `SKILL.md`、脚本、参考资料及 LICENSE。没有额外技能版本号、生成目录文件或手工 ZIP 发布流程。

本方案信任 GitHub HTTPS 与该仓库写入权限；不提供独立发布者签名。用户已确认这一取舍。Git commit、tree 和内容摘要不是发布者签名，不防范账号被盗后的恶意新提交；更新仅在用户操作后采用。

## 客户端读取

1. 显式刷新时，通过 GitHub API 将 main 固定为完整 commit SHA。
2. 在该提交的 tree 中读取 skills 下的直属 Skill 目录，解析 SKILL.md 元数据，不执行任何内容。
3. 用户选择安装时，绑定已展示的 commit 与技能 tree SHA，不再次解析 main 并静默换版。
4. 通过该快照的 tree 取得文件路径、mode、size 和 blob SHA；下载各 blob，核对实际大小及 Git blob 摘要。客户端可另外保存本地 SHA-256，用于修改检测。
5. tree SHA 不变表示 Skill 内容未变；不能因仓库说明或其他技能更新就标记当前 Skill 可更新。

只访问固定 GitHub 官方仓库 API／固定提交资源，不附带模型密钥或业务领取凭证，不把服务返回的任意 URL 当成下载授权。不关闭 TLS 校验，不静默切换第三方镜像。

## 文件与安装边界

- 拒绝截断目录响应、重复／大小写冲突路径、路径穿越、绝对路径、符号链接、gitlink 和不支持的文件类型。
- 读取流设置超时、文件数量和字节上限；失败不伪装成空目录，不替换已有可用副本。
- 安装使用客户端自己的受控目录，先准备与验证，最后切换；不覆盖用户个人／项目 Skill，不共享两个客户端可写的安装目录。
- 不执行安装脚本、运行时安装、付费 API 或生成任务；Skill 安装不增加宿主工具权限。
- 缓存来源、commit、tree 与本地文件身份，以便说明当前版本及处理更新。单纯 UI “已安装”不等于模型已加载或脚本依赖可用。
- 下架不自动删除已安装内容，卸载与启停遵循对应客户端生命周期；历史对话中的指令不会被撤回。

## 验证范围

本仓库测试验证 Skill 结构、参数与本机假服务，不替代客户端正式安装入口验收。DSH 和 ai-pi 的适配、缓存、安装记录与界面分别由其仓库维护；本仓库不引入运行时库或 npm 安装依赖。
