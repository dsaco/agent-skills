# Skill 目录分发说明

## 分发单位

公开仓库 `dsaco/agent-skills`，默认分支 `main`。每个 Skill 位于 `skills/<name>/`，其 `SKILL.md` 的 name 与目录名一致。目录包含运行所需的脚本、参考资料、配置和独立 LICENSE，可脱离本仓库其他技能使用。

本仓库按 GitHub 源码目录分发，不要求每个 Skill 单独设置版本号、标签、Release 或手工 ZIP。仓库可以持续增加不同用途的 Skill，不将当前媒体生成技能的依赖作为整个集合的统一运行条件。

## 获取方式

- 使用第三方 Skills CLI：`npx skills add dsaco/agent-skills --skill <name>`。
- 克隆仓库或下载 GitHub 源码 ZIP，手动安装完整 `skills/<name>/`。
- 本地开发版本可通过目录导入，或使用 Skills CLI 的本地路径来源。

具体命令见 [README](../README.md#获取与安装)。只复制 `SKILL.md` 会遗漏脚本或参考文件；应保留完整目录，包括其中的 `package.json`（若有）。

## 版本与信任

GitHub 上已推送的内容才是远程可安装内容；本地改动不等于已发布。需要复现某个版本时，使用精确 Git commit 对应的源码，并记录来源与提交；其他安装工具是否支持固定版本及如何检查更新，以其文档和实现为准。

本仓库不提供独立发布者签名。Git commit、tree 或内容摘要可用于标识和校验内容，但不是发布者签名，也不能防止仓库账号被盗后的恶意提交。使用者应审阅技能及脚本来源，再授权执行。

## 仓库与工具的职责

| 本仓库负责 | 宿主／安装工具负责 |
| --- | --- |
| 独立 Skill 目录、元数据、依赖说明和许可 | 技能发现、安装路径、启用和同名来源优先级 |
| 通用流程、确定性脚本和测试 | 命令执行权限、凭据注入和工具可用性 |
| 记录来源、变更及已验证范围 | 下载、版本解析、内容校验、缓存、更新和卸载 |

本仓库不维护应用专用安装器、设置界面、技能市场或客户端发布。不会把特定客户端的校验、缓存和安装策略当作所有安装方式的保证。

更新或替换已安装技能由用户决定；安装不增加宿主权限、不配置业务凭据，也不构成实际付费调用的授权。安装工具可能自行下载依赖或收集使用信息，其行为不等同于技能脚本行为，应按该工具文档判断。

## 验证边界

仓库测试覆盖技能结构、脚本和离线模拟行为；不自动证明第三方安装器、任意宿主、操作系统或真实服务已兼容。当前验证范围见 [status.md](status.md)，模型参数与来源见各 Skill 文档。
