# fal-ai 来源与验证

## 已确认的范围

用户选择以 ai-pi 图片完整版为基础，采用 MIT，在独立仓库维护。暂不加入全局版视频，不修改原副本或消费者。本仓库不包含 GitHub 下载器、签名目录、Release 自动化或任何 VM 服务。

## 两份来源对比

| 项目 | 原全局版 | ai-pi 版（本次基线） |
| --- | --- | --- |
| 调用 | 多个 JavaScript 脚本，依赖 @fal-ai/client | 单一 fal.mjs 入口，Node.js 22+ 标准库 |
| 媒体 | 图片及视频 | 图片生成／编辑、去背景、深度／姿态 |
| 任务恢复 | 原有脚本各自处理 | request.json；status/result/download/cancel |
| 分发要求 | 安装 npm 依赖 | 无需安装依赖 |

导入源目录为 ai-pi 的 `resources/local-skills/fal-ai/`，项目提交 `52f1ec1ab3a8e3032359158df247765daa02d739`，该目录最近提交 `b17912891a43ad699f52d2a4d38e883ce6d7393b`。10 个源文件的初始 SHA-256 记录在 [fal-ai-source.json](fal-ai-source.json)，只用于溯源，不是发布签名，也不要求未来改动保持这些摘要。

未复制 node_modules、缓存、真实任务记录、密钥或第三方 SDK。原目录没有独立许可证，本仓库按照用户对原创内容的明确授权补充 MIT，并在独立 Skill 中保留 LICENSE。

## 本仓库改动

- 保留原始 Skill 名称、触发描述、16 个端点及参数边界；参考文档按需加载。
- 添加独立安装／环境说明、MIT 和仓库离线验证入口。
- 修复 `scripts/fal.mjs` CLI 入口判断：原来直接比较 argv 路径与 import.meta.url，macOS 路径别名导致路径不一致时会静默跳过执行；现在比较 realpath。保留以模块导入时不自动运行的行为。此修复尚未同步回两份原 Skill。
- 新增结构与可移植性检查：白名单、本地引用、元数据、许可，移动到中文／空格目录、路径别名、无 Key dry-run 和无依赖运行。
