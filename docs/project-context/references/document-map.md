# 文档分工与维护规则

主流程见[技能草稿](../skill-draft.md)；本页用于选择事实来源与文档路径。默认采用“长期规则 → 开发导航 → 剩余任务／专题证据”的分层，不强制文件数量。

## 职责映射

| 内容 | 默认位置 | 维护边界 |
| --- | --- | --- |
| 项目定位、范围、使用入口 | README；确实缺少时 `docs/project.md` | 面向使用者，不复制内部任务列表 |
| 长期协作规则、读取与收尾条件 | `AGENTS.md` | 不存任务、功能清单和完成记录 |
| 开发导航、命令与配置来源、主题索引 | `docs/development.md` | 命令和版本指向真实配置，细节留专题 |
| 当前执行、剩余验收、阻塞／暂停 | `docs/STATUS.md` | 只留剩余工作和完成／恢复条件 |
| 当前实现、约束、验证入口与覆盖边界 | `docs/validation/<topic>.md` | 同一主题一份有效说明，不拆成相互重复的实现与验收文件 |
| 多专题共用的测试与证据规则 | `docs/validation/testing.md` | 专题只补本主题差异，不各自复制通则 |
| 仍指导决策的调研 | `docs/research/<topic>.md` | 写问题、依据、结论或待确认点；不当作已实现事实 |
| 未执行的方案 | `docs/plans/<topic>.md` | 获准进入执行后，才在状态页加入具体任务并回链 |
| 长期决定及理由 | 已有 ADR 或决策文档 | 状态明确，保留接受／取代关系，不当任务流水 |

路径是默认建议。沿用已有 `docs/README.md`、小写 `status.md`、设计规范、专题和任务系统；没有强制迁移。大小写一致性按真实目录检查，避免 Mac／Windows 上的同名冲突。只有存在有效内容才创建分类目录，不为目录整齐批量生成占位文档。

## STATUS 只回答“还剩什么”

开发进度不是完成清单：从专题了解当前能力，从 STATUS 了解下一步。

| 区域 | 条目至少说明 |
| --- | --- |
| 当前执行 | 已进入本次工作范围的目标、剩余动作、验收条件；相关专题存在时加链接 |
| 剩余验收 | 尚缺的平台、环境或用户路径验证，以及合格条件；不把未授权的真实调用放进当前执行 |
| 暂停／阻塞 | 现象与证据缺口、停止原因、恢复所需信息／环境／授权；不自动重试 |

例如：专题记录“导出已实现，入口关闭；离线用例通过，浏览器未验证”，状态页只写“确认开放条件并完成浏览器验收，标准是经实际入口生成并检查目标文件”。完整实现和测试细节不再复制到状态页。

任务完成后先维护专题当前结论，再移除该待办；部分完成则保留剩余范围。没有待办就写“暂无待办”，空栏目删除，不用近期成果、用例数、截图和提交记录填满页面。状态页不承担完整路线图，也不代表下一项任务已获授权。

## 专题承载当前事实与证据

每个专题按需覆盖：当前行为和限制、真实使用／开发入口、验证方法、已有依据、未覆盖边界。版本与脚本以项目真实配置为准，文档不维护第二套易过期的精确依赖清单。

- 将实现、启用、部署与验证视为不同维度；没有部署的文档项目可以不设部署字段。
- 证据注明实际对象、环境、来源及必要的版本／日期；既有验证可保留，但不要更新日期冒充重测。测试存在、mock 通过或截图路径都不能直接证明正式使用成功。
- 当前结论和仍有用的复现／检查方法留下；逐轮通过流水与临时诊断噪声不堆入专题，必要的非敏感原始证据按项目既有存放约定引用。
- 同一主题只保留一个当前有效说明；历史决策、合规审计、法定留存或不可替代证据按项目规则保留，不因“保持精简”删除。

## 从一个目标到收尾

生成的 AGENTS 要让 Agent 先确定用户目标与验收条件，再以小增量推进当前目标；故障先复现并定位，验证按改动影响选择，最后由正式使用入口或文档交付标准核对结果。详尽验证方法放测试专题，普通小改动不必创建新计划或 ADR。

满足约定验收后，同步相关用户说明／专题与导航，再处理 STATUS；完成必要且已授权的清理后停止。验收被环境或授权阻断时，保留可核对依据和恢复条件，不延伸成无关重构、权限扩大或反复尝试。

## 作用域与保留策略

AGENTS 是协作指引，不是安全沙箱或执行授权；宿主是否加载、如何处理作用域需在实际工具中确认。本草稿不复制某个宿主的加载顺序，也不把委派或外部操作授权写成通用默认值。

文档整理先保留独有有效信息、修复引用，再在已授权范围内处理冗余。迁移、删除文件或重写历史不能用模板约定替代本次授权；无明确保留策略时先询问，不额外搭建空归档体系。已有 ADR 保留原编号和状态，未确认提案不写成已接受决定。
