# 参考流程与取舍

本次只读参考用户指定的本地 `ai-pi` 项目，源码版本与文件摘要见[来源记录](../sources.json)。观察对象是项目文档，不是独立运行评测；它能展示现有约定，不能证明该流程已提高效率或适合所有项目。

## 采用的模式

| 来源文件 | 可复用做法 | 草稿中的落点 |
| --- | --- | --- |
| `AGENTS.md` | 一个当前目标、小增量验证、验收后停止；长期规则不混任务历史 | AGENTS 模板的开发方式与收尾 |
| `docs/STATUS.md` | 当前执行、剩余验收、暂停；每项链接详细依据 | 待办模板，替代初稿的进展／近期结果表 |
| `docs/development.md` | 用户说明、开发约束、主题验证、调研与规划分层 | 开发入口模板和职责映射 |
| `docs/validation/testing.md` | 影响驱动的检查选择、故障复现到正式入口、证据与清理边界 | 测试方法模板；具体工具由目标项目提供 |
| `docs/validation/instructions-validation.md` | 一个主题同时说明当前行为、边界、验证入口与已有依据 | 通用专题模板，不复制指令加载机制 |
| `README.md`、`DESIGN.md` | 用户说明和专门规范有独立职责，通过入口引用 | 既有权威文档沿用，不默认新建平行说明 |

本次最重要的改变是 **STATUS 从“记录做到哪”收窄为“指出还剩什么”**：已实现和已验依据属于专题；只有剩余动作与阻断留在状态页。

## 不直接移植的规则

- Pi、Electron、React、平台构建、特定脚本、UI 风格和模型／资源服务约定是来源项目的实现，不是通用 Skill 前置条件。
- 来源项目的子代理许可不是本仓库的授权；草稿不默认要求或开启委派。
- “只维护当前格式、不做兼容”适用于特定产品阶段，不能强加给其他项目。
- 来源项目偏向删除被替代文档且不建归档。本草稿保留“单一当前说明、保全有效信息”的原则，但删除／迁移须在授权范围内，历史决策、审计和留存仍按目标项目要求处理。
- 精确依赖以各项目自己的权威配置为准，不把 `package.json` 或某种包管理器设为所有项目的必需品。
- AGENTS 的发现顺序和工具权限属于宿主实现；这里只保留“指令不是授权”的边界，不复制特定加载逻辑。

未读取或迁入参考项目的凭据、真实会话、任务产物及运行配置值，也未执行其中的构建、测试或外部命令。此处记录的是抽象后的模式和本次取舍，不是来源项目全文副本。
