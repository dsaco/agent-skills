# Volcengine Ark Media

## 按需求选择分支

使用 `node "<技能目录>/scripts/ark-media.js"`，技能目录解析为绝对路径；保留用户任务 cwd，输入输出相对 cwd。参数疑问用 `<动作> --help`。

| 需求 | 必读文档 | 执行路径与结束条件 |
| --- | --- | --- |
| 图片生成、编辑、组图 | [图片参数](references/seedream-image.md)及[任务规则](references/jobs.md) | `image` → 下方新生成流程 |
| 视频生成、图生视频、多模态参考 | [视频参数](references/seedance-2.0.md)及[任务规则](references/jobs.md) | `video-create` → 下方新生成流程 |
| 已有视频进度、成品或补下载 | [视频取回](references/jobs.md#视频取回) | 复用 task id 执行 `video-query`；只查进度则查询一次后报告，取成品则按轮询预算处理并验收 |
| 已有图片响应补下载 | [图片恢复](references/jobs.md#图片恢复) | `image-download --result <响应文件>`；逐项下载后验收，不进入新生成流程 |
| 列出本地图片模型 | 无 | `models`；报告清单及“本地快照，非账户可用性查询”后结束，无需 Key 或预检 |

原样传递用户 prompt。用户明确要求优化视频 prompt 时，才读取[提示词指南](references/prompt-guide.md)。模型能力和价格是导入快照，动态结论以当前官方资料和账户权限为准。

## 新生成流程

仅用于 `image` 和 `video-create`；已有任务从上表恢复。

1. **列产物清单。** 确定动作、模型、输入顺序，以及每项产物的数量、内容和尺寸／时长等要求；显式要求映射为参数，省略项按对应参数文档处理。影响费用或用途的歧义先确认；能力不匹配时由用户确认替代。**完成：每项要求都有参数或明确的能力边界，素材使用和实际生成已获授权；仅要求预览时，执行到第 2 步即结束。**
2. **预检。** 为新任务选择唯一输出名称，执行 `--dry-run`，核对请求和输出路径。**完成：预检通过且与产物清单一致；若仅预览，交付请求摘要与未验证项后结束。**
3. **提交留据。** 按任务规则配置环境，移除 `--dry-run`，提交一次。**完成：图片响应已保存；视频响应已保存且取得非空 task id。异常则转入[失败分流](references/jobs.md#失败分流)，记录结果未知或失败，不以重新提交完成此步。**
4. **取回验收。** 图片使用同步下载结果；视频按[视频取回](references/jobs.md#视频取回)处理。随后执行[验收与交付](references/jobs.md#验收与交付)。**完成：产物清单每项均有文件或失败／待处理状态，每项要求均有检查结论或未验证说明。**
