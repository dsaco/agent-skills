# Seedance 视频提示词

仅在用户明确要求优化视频 prompt 时应用。以下为原技能的经验性建议，不是模型硬性限制或效果保证。

来源：[火山方舟提示词指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)。媒体数量和接口字段以[视频参数](seedance-2.0.md)为准。

## 先确定任务语义

| 意图 | 表述 |
| --- | --- |
| 参考素材生成新视频 | `参考图片N中的主体／视频N的运镜／音频N的音色，生成……` |
| 局部编辑已有视频 | `严格编辑视频N，将……修改为……，其他主体、动作、镜头和场景保持不变。` |
| 延长视频 | `生成视频N之后的内容……` 或 `向前延长视频N……` |
| 组合任务 | `参考图片N的风格，严格编辑视频X，将……` |

编辑和延长直接称“视频N”，避免被理解为仅参考。编号按实际输入顺序对应；`asset://` 也用图片／视频编号指代。

## 主体锚定

素材中有多个主体时，用 2–3 个稳定静态特征定义角色，再持续使用同一标签：

```text
将图片1中穿红色连衣裙、戴草帽的女人定义为主体1。
```

未定义标签时，用“主体@图片N”明确来源。人物参考优先选单人清晰照片；脸、服装、环境需要不同参考时分别说明用途。空间关系复杂时优先提供参考图，避免用大段文字弥补含糊素材。

## 镜头与时序

简单任务使用：**主体 + 动作 + 场景 + 镜头 + 风格 + 必要约束**。

复杂任务按事件顺序分镜，每个镜头说明主体动作、位置变化、运镜和必要音频。一个镜头优先一种运镜；精确秒级控制的效果不稳定，用户未要求时采用自然时序。

```text
镜头1：全景，主体1缓慢走进雨巷，固定镜头，远处有雨声。
镜头2：中景，主体1停下，抬头望向灯光，镜头缓慢推近。
```

把情绪写成可见动作，例如“低头，肩膀轻颤”，而非只写“悲伤”；写明动作部位、幅度、速度。细微连续动作通常更容易保持稳定，但用户要求高强度动作时保留其意图。

## 台词、音效与文字

| 内容 | 建议标记 |
| --- | --- |
| 音乐 | `（背景中播放轻柔钢琴音乐）` |
| 音效 | `<远处传来狗叫声>` |
| 台词 | `{你好，世界}`；非默认语言明确标注，如 `用日语说道{こんにちは}` |
| 字幕 | `【第一章：启程】` |

台词统一语言，专名按需求保留；生僻字、多音字影响发音时可征得用户同意后换词。用户不需要文字时可写“画面仅呈现影像，无字幕”，但不擅自删除需求中的台词或字幕。

## 按问题定向调整

| 问题 | 调整方向 |
| --- | --- |
| 人物外观漂移／重复人物 | 清晰单人参考，固定主体标签，说明每个镜头的人数和角色 |
| 风格漂移 | 用一张主要风格参考，统一风格描述；减少互相冲突的素材 |
| 动作或特效含糊 | 参考视频明确到动作、轨迹或运镜，而非只写“像这个” |
| 音色偏离 | 写明音色和语气特征，台词风格贴近参考音频 |
| 视频结尾噪音 | 优先考虑后期音频淡出；重新生成按新付费任务处理 |

参考素材按角色、场景、运镜、节奏分工，优先少量清晰素材。优化交付时保留所有必要要求，并说明删减或改写的歧义；质量建议不构成再次生成的授权。
