## 新任务流程

使用 `node "<技能目录>/scripts/fal.mjs"`，技能目录解析为绝对路径；保留用户 cwd，输入与输出相对 cwd。模型文档定义任务参数；[任务与恢复](references/jobs.md) 定义素材、认证、输出及失败处理，新建任务时一并读取。

1. **列产物清单。** 按模型文档选择端点，使用用户指定素材并保留顺序；列明数量、类型及尺寸／透明度等要求。显式要求映射为参数，省略项交给 API 默认。模糊要求说明采用的解释；影响费用或用途的歧义先确认。遵循用户指定的服务商与模型；超出清单时说明差异，由用户确认替代。**完成：每个预期产物及关键要求都有参数、默认值或已说明的能力边界，输入足以组成命令。**
2. **预检。** 执行 `--dry-run`，核对端点、素材顺序和显式参数；语法疑问查看 `--help`。预检无需 Key、不联网、不写产物，远程素材只校验 URL。**完成：预检通过且计划与产物清单一致；用户仅要求预览时，交付请求摘要后结束。**
3. **提交留据。** 用户要求实际处理时，按任务文档准备环境并移除 `--dry-run`，提交一次。**完成：保存 requestFile 与请求 ID；异常则按任务文档分流，提交状态不明时先核查，不重提。**
4. **取回验收。** 按[取回与交付](references/jobs.md#取回与交付)持续处理，**完成：产物清单逐项满足该节的验收与交付条件。**
