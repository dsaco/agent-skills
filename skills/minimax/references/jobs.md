# 任务记录与恢复

每次新请求指定一个尚不存在的任务目录。脚本拒绝覆盖已有目录；同一记录的查询／恢复通过`.minimaxLock`串行执行。异常退出若留下锁，先确认无活动进程，再由操作者删除该任务目录内的孤立锁，不批量清理。

| 文件 | 用途 |
| --- | --- |
| request.json | 提交前写入，含动作、官方主机、规格、素材证据和请求摘要；无API Key，内嵌素材用长度和hash替代 |
| response.json | 首次HTTP响应及业务响应；包含task_id、file_id、voice_id或媒体数据 |
| status.json | 已有视频任务最新查询响应 |
| downloads.json | 下载文件路径、大小、SHA-256和数量；明确未替代解码或用户验收 |

请求体原文件和素材由用户任务目录保存。脚本不读取系统其他项目的配置，不自动载入`.env`。以环境变量注入凭据；config只显示已配置与否，API主机仅接受官方HTTPS地址。国际账户用global，国内cn；有任务ID后不可换区域另提任务。

## 视频

`videoCreate`仅提交一次，立即保存返回的任务ID。需要成品时继续：

```sh
node "<技能目录>/scripts/minimax.mts" videoQuery --job outputs/shot01/request.json --wait 1800
```

每10秒查询同一ID；wait=0或省略时仅查询一次，成功则顺便下载。等待预算到期返回pending，云端任务仍可能运行。进程仍在执行时等待该进程，不启动第二个生成任务；轮询没有固定完成时间保证。

如果status.json已显示succeeded，但下载中断：

```sh
node "<技能目录>/scripts/minimax.mts" recover --job outputs/shot01/request.json
```

下载地址失效时重新videoQuery同一任务取得新链接。官方查询接口仅支持近期任务，及时保存产物。

## 同步语音／图片／音乐

完整response.json存在且业务成功时用recover补下载／重新解码，不重复生成。Hex音频恢复离线完成；URL下载需要联网，且不携带API密钥。已存文件与本次恢复内容hash一致时保留，内容不一致停止覆盖。

本工具不自动重定向携带认证的API请求。下载返回重定向时保留响应并报告，由操作者核对目的地址后处理，不能重新生成。

## 错误分流

- HTTP成功但base_resp.status_code不为0：仍为业务失败，不把响应中的空文件当成品。
- 上传／生成POST超时、断线或响应无法保存：结果可能未知。保留request.json；有task_id就查询原任务，没有则核对控制台记录／账单，不自动重发。
- 视频failed／cancelled／expired：报告任务ID与已存错误。只有用户授权新尝试且原因已处理时才创建新目录提交。
- 下载失败：恢复同一响应；已成功的生成不重做。
- 余额、认证、权限、模型不可用或内容限制：停止，说明具体服务错误；不自动更换模型、账户、区域或规避限制。
- 实际语音的年龄感、情绪、角色匹配和视频表演属于质量判断。文件可解码不等于用户接受。

所有任务记录可能包含台词、声音和签名媒体地址，留在用户本地任务目录，不上传到技能源码仓库。只向聊天输出必要状态，不全文打印凭据或大段hex/base64。
