<a id="workflow"></a>
## 工作流程

1. **定界。** 选择“咨询／只读排障／变更”，列出本次问题或验收项。**完成：模式与清单明确；远程操作的目标 VM、环境和允许动作无关键缺项，咨询中的假设已标注。**
2. **取证并分流。** 从主题参考中的官方来源核对平台事实，缺入口时查[文档索引](https://exe.dev/docs.md)；执行命令前按[执行位置](references/operations.md#查证与执行位置)核对当前帮助。**完成：清单每项均有关联证据或明确未知，事实、推测和建议分开。**
   - **咨询：** 交付逐项结论、来源日期及适用限制，结束；不执行远程命令。
   - **只读排障：** 仅执行已获准的查询，交付观察、原因判断和待批准的修复建议，结束；不进入变更步骤。
   - **变更：** 进入第 3 步。
3. **计划并执行（仅变更）。** 逐项写明目标、执行位置、命令、影响与费用、回滚办法；授权已覆盖则执行，未覆盖则先确认。**完成：每项标记成功／失败／未执行／结果未知并有依据；失败或未知时暂停后续操作，先核实，再按授权决定继续或回滚。**
4. **验收并交付（仅变更）。** 对照第 1 步清单回查，采用主题参考中的检查项。**完成：每项列出预期、实测结果或未验证原因、偏差与遗留风险；全部实际操作及回滚状态均有记录。**

<a id="boundaries"></a>
## 授权与凭据边界

- 部署、重启、安装依赖、权限／公开性调整、邀请、凭证创建、integration 附着、购买、模型请求及删除属于变更，须匹配用户授权的对象和范围。命令模板先替换占位符；结果不明的收费或创建操作先核查，禁止自动重提。
- 沿用已有 SSH 认证，保持主机密钥校验；指纹变化先核实。凭据仅确认本地保存路径和是否就绪，私钥、真实 `.env` 和 token 正文不得进入模型上下文、命令明文参数、日志或仓库。
- **禁止代用户上传真实密钥到平台或其他网络服务。** 需要平台托管时，提供用户自行配置的指引；获准生成的新凭证由本地安全流程接收，工具结果只报告状态。
- 破坏性验证使用另行获准的隔离环境和合成数据；清理范围限定为本次创建且明确获准删除的资源。仅保留必要的脱敏证据，任务记录放用户工作目录。
