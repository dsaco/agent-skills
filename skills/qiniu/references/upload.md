# 配置与上传

## 环境与授权

四项环境配置由 [README](../README.md#四个环境变量)定义；上传前一次性校验全部缺失项，仅报告变量名。Key 用于 SDK 本地签名，上传令牌只在上传请求中使用，不输出或保存；脚本不读取任何真实 `.env` 文件。

`QINIU_BUCKET` 接受 3–63 位小写字母、数字、连字符，首尾为字母或数字。`QINIU_DOMAIN` 要求完整 HTTPS origin，可含端口，可有末尾 `/`；拒绝 URL 中的用户名、密码、路径、查询与片段。它是交付域名，不是上传服务地址；不要填七牛上传 API 域名或未经授权的空间域名。

地域由官方 SDK 根据 AK 和 Bucket 查询，无需第五个环境变量。脚本固定 HTTPS 上传；`--https` 仅兼容旧命令。`--accelerate` 仅在用户明确要求且空间已开通时启用，可能增加费用。

上传会将文件发送到七牛，公开空间和绑定域名可能使 URL 持有者访问内容；脚本不判断 Bucket ACL、不创建私有下载签名、不更改域名或权限。安装／预览不构成上传授权。

## 文件与对象 key

- 必填 `--file`，相对用户 cwd；只接受普通文件，拒绝目录及文件自身为符号链接。允许零字节对象，上传成功仍不代表其内容符合用户预期。
- 默认前缀：本地日期 `ai/YYYY-MM-DD`。普通图床、模型参考素材不传 `--dir`，不为任务用途自行发明目录。
- 默认文件名：UUID + 原扩展名；`--keep-name` 保留 basename；`--name` 显式名称优先。修改后缀不转换文件格式。
- `--dir` 仅用户明确要求时使用，去掉首尾 `/`；拒绝空分段、`.`、`..`、反斜杠和控制字符。`--name` 必须是单个文件名。
- 完整 key 在本地限制为 750 UTF-8 字节。访问 URL 对 key 各路径段分别编码，中文、空格、`#`、`?` 不会变成 URL 控制字符。
- dry-run 每次重新生成 UUID；预览检查命名规则，不保证与随后执行的 key 相同。需要固定对象名时由用户明确 `--name` 或 `--keep-name`。

## SDK 与重复上传

沿用官方 `qiniu@7.15.2` 的 FormUploader.putFile，令牌 scope 固定到当前 bucket:key，expires 为 600 秒，`insertOnly: 1` 拒绝覆盖现有同 key 对象；未接入覆盖选项。

SDK 源码的域名／区域重试策略可能在一次调用内重复发送，区域查询还可能使用缓存。脚本不再额外循环或自动重跑；SDK 行为不等于“网络只请求一次”。默认同 key 的仅新增策略可降低覆盖风险，但重试遇到已存在错误时不能推断前一次没有上传成功。

官方依据：[Node.js SDK](https://github.com/qiniu/nodejs-sdk/tree/v7.15.2)、[上传策略](https://developer.qiniu.com/kodo/1206/put-policy)。本技能不实现断点续传或本地任务数据库。

## 结果与恢复

真实上传先输出 `state: uploading` 的非凭据计划，再输出 `state: uploaded` 的成功 JSON。包含 bucket、key、本地路径、size、hash、URL；不输出 SDK 原始错误体、AK、SK 或上传 token。

成功条件为 HTTP 200、返回 key 与请求一致、hash 非空；`urlVerified: false` 表示未主动请求 CDN。区域路由、内容完整性和 CDN 可访问性仍由 SDK／服务与后续验收分别确认。

| 故障 | 下一步 |
| --- | --- |
| 环境变量缺失／非法 | 用户在本地修正配置，不能猜 Bucket 或域名 |
| SDK 缺失 | 告知安装命令，等待用户处理依赖 |
| HTTP 错误、网络超时或结果未知 | 保留 uploading 记录中的 bucket:key，核查控制台；不换新 UUID 自动重传 |
| 同 key 已存在 | 核对已有对象是否为本次目标，不能默认为失败后直接覆盖 |
| 上传成功但链接打不开 | 核对域名绑定、Bucket 权限、CDN 生效与 HTTPS；不重复上传解决访问配置问题 |

脚本不写任务记录文件，Agent 应保留工具返回或在用户授权的任务目录记录结果；记录不进入源码仓库。上传可能产生存储、请求、加速和下载流量费用，预览不会探测真实账户配置。
