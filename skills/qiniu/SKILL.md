# 七牛云上传

使用 `node "<技能目录>/scripts/upload.js"`，将技能目录解析为绝对路径，保留用户 cwd。首次上传前读[配置与运行](references/upload.md)，安装依赖见 [README](README.md)。仅预览无需 SDK 或密钥。

1. **确认上传清单。** 明确每个本地文件及公开分享用途，确认用户授权将内容发送到七牛。默认对象前缀由脚本生成，只有用户明确要求目录／对象前缀时才传 `--dir`。**完成：每个文件与命名要求已确定，敏感文件的外发与可访问范围已确认。**
2. **预检。** 仅准备 Bucket、域名，执行 `--file <路径> --dry-run`，检查文件、目标空间、命名方式和 URL。**完成：清单每项预检通过；仅要求预览时交付计划后结束。**
3. **上传。** 确认四个环境变量齐全且 SDK 可用，移除 `--dry-run`，每个文件调用一次；保存命令输出中的 bucket、key 和结果。**完成：每项获得 uploaded 结果或明确失败／未知状态；结果未知先核查控制台，不换 UUID 自动重传。**
4. **交付。** 对照清单给出所有成功对象的 key、hash、URL 和失败项；说明 URL 是否实测可访问。**完成：每个文件均有去向，上传成功不等同于域名绑定、公开访问或 CDN 生效已验证。**

SDK 可能在一次 putFile 调用内切换上传域名重试，详见运行文档；脚本使用仅新增策略保护同 key 对象。需要覆盖、私有签名链接或空间管理时说明能力未接入，先确认方案。
