# 编曲参考

数值是起点，不是模板；按风格取用。标“实测”的行为于 2026-10 在 strudel.cc 核对过。

## 源码骨架

```js
// <曲名> — v1
// 4/4 · 90 BPM · 24 小节 · 64 秒 · 无缝循环
// 配器：鼓组、合成低音、电钢和声、主奏；段落：A 1–8 · B 9–16 · A' 17–24

setcpm(90 / 4)

// 每个参数恰好 1 小节；一层的参数个数 = 总小节数或其约数
const bars = (...patterns) => cat(...patterns)

const drums = bars(
  "bd ~ sd ~", "bd ~ sd [~ bd]", /* … 共 24 个 */
).s().bank("RolandTR909").gain(".8 .5 .7 .5").lpf(1800).room(.04).orbit(1)

const motifA = bars("c5 e5 g5 ~", /* … 共 8 个 */)
const motifA2 = bars("c5 e5 g5 a5", /* … 共 8 个 */)
const lead = arrange([8, motifA], [8, "~"], [8, motifA2])   // 1–8 · 休息 9–16 · 17–24
  .note().s("gm_epiano1").clip(.8).gain(.12).orbit(3)

stack(drums, lead)
  .compressor("-20:3:6:.006:.11")
  .postgain(.7)
```

头部规格行和段落计划是预检时逐层对照 `sounds[*].bars` 的依据；每层上方用一行注释写它的角色。

## 曲式写法

| 写法 | 行为 | 用途 |
| --- | --- | --- |
| `cat(p1, p2, …)` | 单小节参数依次各占 1 小节 | 通谱写法：每小节一个 pattern |
| `arrange([n, a], [m, b])` | a 连续占 n 小节并按自身顺序播放，随后 b 占 m 小节 | 段落拼接；单小节 groove 重复 n 次 |
| `stack(a, b)` | 同时叠加 | 叠层 |
| `"<x ~ ~ ~>"` | 每 4 个 cycle 出现一次；放进 arrange 段时从段首起算 | 段首标记、偶发事件 |
| `"a1@4"` · `"[c4,e4,g4]"` · `"[a b]"` · `"~"` | 延长 · 和弦 · 细分 · 休止 | 节奏与和声 |
| `.transpose(-12)` 或 `.add(note(-12))` | 移低八度 | 八度叠加 |

实测易错点：

- 多小节段落前后拼接只用 `arrange`。`cat(a, b)` 遇到多小节参数会逐小节交替（a 第 1 小节、b 第 1 小节、a 第 2 小节…）；`stack(a, 休止, b)` 让 a 与 b 同时响。
- `"a1 c2".note().sub(12)` 不改变音名，八度叠加用上表写法。
- 每层长度必须等于总小节数或其约数，否则下一遍与第一遍错位，`--loop` 预检会列出不一致的小节。
- `rand`、`perlin`、`?`、`sometimes*`、`degradeBy` 按绝对时间取值：同一位置每次渲染结果相同，但下一遍与第一遍不同。需要变化感时写成固定 pattern 或 `<…>` 轮换；`Math.random()` 每次求值都变，作品中不用。

## 小节数与密度

- 以 4 小节乐句为单位：8 小节适合短循环，16 小节两段对比，24 小节三到四段渐进，32 小节完整乐句。
- 精确时长可能逼出非常规小节数：60 BPM · 4/4 · 60 秒 = 15 小节，可分 3×5 或 4+4+4+3；只要求“约 60 秒”时，16 小节（64 秒）更利于 4 小节乐句。
- 慢速却要轻快：鼓组用 half-time，再用十六分踩镲或分解和弦提供推进。
- 换 BPM 时重新计算小节数，并按新的每小节时长改写节奏型和段落，不只改 `setcpm`。

## 调式与情绪

| 方向 | 起点 |
| --- | --- |
| 明亮、轻快、儿童向 | 大调；I–vi–IV–V、I–IV–V；旋律以级进为主 |
| 冒险、推进 | 小调五声；上行动机；低音八分跳动 |
| 神秘、暗、仪式感 | 小调五声或弗里几亚（含 ♭2）；低音 ostinato |
| 平静、漫游 | 大调稀疏旋律加分解和弦，多留白 |

背景音乐用短动机和有限音域；主旋律之外给一条应答声部或句尾点缀，避免每小节都满。

## 混音

- 各层用 `.gain()` 定平衡，总线用 `.compressor("-20:3:6:.006:.11").postgain(.6–.8)`。总线末尾的 `.gain()` 会覆盖各层增益，整体音量只改 `postgain`。
- 同一 orbit 共享 `roomsize`、`roomfade`、`delaytime`、`delayfeedback`；`room`、`delay` 是每层的发送量。空间设置不同的层放进不同 orbit，预检的 `orbitConflicts` 会列出冲突。
- 多层 `distort`／`shape` 叠加时，postgain 即使在 .6–.8 也可能连续满幅削波；校验报削波时先降 postgain 或失真量。
- 同一批作品要对齐响度：各自混音的作品 RMS 可能相差 10 dB 以上，切换曲目时音量跳变明显。建议把 `rms_dbfs` 对齐到约 ±2 dB 内或遵循项目规范；RMS 只是粗略指标，需要感知响度时用 `ffmpeg -i <文件> -af ebur128 -f null -` 读 Integrated LUFS。
- 需要转 MP3／OGG 时，峰值至少留 1 dB 余量。

## 循环衔接

- 最后一小节导回第 1 小节：属和弦、上行引句或减少末拍密度，让第 1 小节听起来是承接而不是重新开头。
- `--loop` 预检一致，说明 REPL 连续播放时听到的接缝就是 WAV 循环的接缝（尾音除外）。
- 尾音：长 release、高反馈 delay、大空间（如 room ≥ .3、roomsize ≥ 2）或长采样（锣、风声）靠近末小节时，单循环渲染的开头缺少上一遍的尾音。把长尾事件放在离末小节较远处，或改用增强双循环。
- 采样用 `.clip()` 控制时值（事件长度的倍数）；需要采样延续更久时，同时考虑它是否跨过接缝。
